# Cálculo IRRF

Cadastro de funcionários com cálculo do Imposto de Renda Retido na Fonte.
Inclui testes, interface acessível, persistência com `localStorage` e estado compartilhado via Context API.

## Como rodar

É esperado a utilização do [Vite+](https://viteplus.dev) (`vp`) ou `pnpm` para instalar e rodar. Outros package managers devem funcionar sem problemas, mas irão gerar um novo lockfile.

```bash
pnpm install
pnpm dev         # desenvolvimento
pnpm test        # rodar todos os testes
pnpm build       # gera diretório /dist com html, css e js minificados
```
